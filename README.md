# 📄 pdfjin-reorder

> Reorder, duplicate, or delete PDF pages by index by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-reorder.svg)](https://pypi.org/project/pdfjin-reorder/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/reorder-pdf.html](https://pdfjin.com/pages/reorder-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-reorder
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-reorder.git
cd pdfjin-reorder
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-reorder --help
```

Use in Python:
```python
import pdfjin_reorder
```

---

## 🧪 Testing

```bash
pip install pytest
```
